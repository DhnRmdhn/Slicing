# Portfolio Website - Dhani Ramadhani

https://dhn-dhani-ramadhani.vercel.app/

Slicing dari [dhnrmdhn.github.io](https://dhnrmdhn.github.io/) yang sebelumnya pernah aku buat waktu semester 2.

Waktu itu website ini dibuat **full AI**, dan jujur aja saat itu aku belum benar-benar paham apa itu HTML, CSS, dan JavaScript.
Nah, sekarang karena sudah lebih paham tentang struktur dan isi dari HTML, CSS, dan JavaScript,
tantanganku adalah **meniru kembali website portfolio yang pernah aku buat sebelumnya** tanpa cuma bergantung sama AI 🤏.

Isi website meliputi:

* Profil singkat
* About Me
* Skill
* Riwayat pendidikan
* Kontak dan media sosial

## ✨ Fitur :v

### 🌗 Light & Dark Mode wkwk

Website memiliki fitur untuk mengganti tampilan antara mode terang dan mode gelap.

### 👤 Profil 🗿

Menampilkan nama, status sebagai mahasiswa Informatika Universitas Jember, serta foto profil.

### 📖 About Me

Berisi penjelasan singkat mengenai latar belakang dan fokus pembelajaran dalam bidang IT, khususnya backend dan web development.

### 💻 Skill

Menampilkan beberapa kemampuan yang sedang dipelajari:

* Backend
* Database
* Frontend

Skill ditampilkan menggunakan progress bar sebagai gambaran tingkat pembelajaran saat ini, **padahal ga jago.**

### 🎓 Education

Menampilkan riwayat pendidikan dari SMA hingga perkuliahan di Fakultas Ilmu Komputer Universitas Jember.

### 📱 Contact

Menyediakan tautan menuju Instagram dan GitHub untuk memudahkan pengunjung menghubungi atau melihat profil saya.
